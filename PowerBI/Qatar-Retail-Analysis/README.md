# Qatar Retail Sales Analysis

An end-to-end retail analytics project using Excel, Power Query, Power BI, and DAX.

## Project Overview

This project analyzes retail sales data to understand revenue, costs, profitability, and year-over-year performance.

## Tools Used

- Excel
- Power Query
- Power BI
- DAX

## Key Business Questions

- How is profit changing over time?
- Which categories contribute most to profit?
- Which products are most profitable?
- How does discounting affect profit?
- How does performance differ between years?

## Dashboard

The Power BI report contains:

- Executive Overview
- Sales Performance
- Profitability Analysis

The dashboard includes dynamic filtering and year-over-year analysis.

## Data Preparation

The raw dataset was cleaned using Power Query, including:

- Standardizing city names
- Handling missing values
- Correcting data types
- Removing duplicate records
- Creating calculated profit fields
